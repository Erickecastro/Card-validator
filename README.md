# Card Validator

> A simple C# console application that validates credit/debit card numbers using the **Luhn Algorithm** and identifies the card brand based on its prefix and length.

## Features

* Validates card numbers using the Luhn algorithm.
* Identifies the following card brands:

  * Visa
  * Visa Electron
  * Mastercard
  * American Express
  * Diners Club
  * Discover
  * JCB
  * Maestro
  * Solo
  * Switch
  * Laser
  * enRoute
* Accepts card numbers with or without spaces and hyphens.

## Technologies

* C#
* .NET
* Regular Expressions (Regex)

## Example

```text
Enter the card number:
4111 1111 1111 1111

Valid: True
Brand: Visa
```
